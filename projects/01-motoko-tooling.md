Led development of programming language tooling, including the VS Code extension, formatter, live-reload development server, embed service, starter projects, and compiler browser support.

The extension grew to more than 85,000 installs. The tooling connected editor workflows with browser and Node.js environments using TypeScript and WebAssembly.
