---

Pandas GPT brings natural-language requests into a pandas workflow. Use `df.ask(...)` to transform data, answer questions with tables, or create visualizations, with options to preview generated code or allow changes to the original DataFrame.

The library supports configurable model backends, including OpenAI, Azure OpenAI, and LiteLLM providers such as Gemini, Hugging Face, and OpenRouter. Custom completers are also supported.
