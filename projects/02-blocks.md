Blocks is an online visual smart contract builder for the Internet Computer blockchain. Inspired by node-based editors such as Blender Nodes and Unreal Engine Blueprint, it lets developers build Motoko smart contracts by connecting blocks in a dataflow graph, then compile, deploy, and test them directly from the browser.

Built with React and JavaScript with a collaborator, and funded by a $25,000 DFINITY Developer Grant. Features include interactive tutorials, example and template contracts (such as fungible tokens and DIP721 NFTs), pretty-printed Motoko output, custom expression blocks that mix visual logic with Motoko syntax, GitHub package imports, built-in test cases, and an embeddable `react-blocks-editor` npm package. The repository has 160+ GitHub stars.
